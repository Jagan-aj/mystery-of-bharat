## 📜 Historical Context
In **1825**, over 1,500 Paliwal Brahmins mysteriously evacuated 84 prosperous agricultural villages in the Thar Desert overnight. Rather than surrendering their ancestral water-harvesting knowledge and dignity to the tyrannical Diwan Salim Singh, they vanished without leaving a trace.

This game takes the player through an interactive journey to uncover their ancient Khadin bund systems, stepwells (Bawaris), and historic temples.

---

## ✨ Features & Technical Highlights
- **Pure Vanilla Stack:** 100% written in HTML5 Canvas 2D and Vanilla JavaScript with **zero external libraries or engines**.
- **Custom Pseudo-3D Engine:** Vertex lighting, perspective projection, camera trauma shake, and depth sorting.
- **Dynamic Lighting:** Real-time point light mapping for torches, campfires, and diyas.
- **Procedural Sound:** Built-in Web Audio synthesizer generating footsteps, temple bells, and desert winds.
- **Integrated Voice Narration:** Web Speech API voice guide providing lore commentary.
- **Interactive Puzzles:** Cultural riddles, Navagraha chamber mechanics, and Vedic ciphers.
